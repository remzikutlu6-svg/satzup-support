# SatzUp support

Static GitHub Pages website. Publish this directory's contents at the root of a separate public repository named `satzup-support`. Enable Pages from the main branch, root directory. There is no build, server, framework, analytics script, or cookie requirement.

The pages describe the prepared SatzUp 1.0 account deletion implementation. Publication is gated on configuring a real public support email and deploying and verifying the deletion backend. The preparation workspace contains the configuration, deployment instructions and release report outside this public directory.
